# Reunião de revisão da Sprint 1
*Participantes:* equipe TechFlow Solutions e representante da startup de logística.
*Objetivo:* demonstrar o protótipo da v1.0 e coletar feedback.

### Data: 20/11/2026 - 19:00 BRT, UTC-3

### Apresentado:
- CRUD de tarefas
- quadro em colunas por status
- testes com pytest
- CI para testes automaticos.

### Feedback do cliente
- **Melhorias de interface:** cores por status, mensagem de erro estilizada, espaço entre botões, confirmação antes de excluir, nome TrilhaFlow na tela. Com intenção de deixar o sistema menos rudimentar
- **Novo pedido:** Sistema de Login para questões de segurança, com nivel de controle baseado em posição e necessidades; Gerentes possuem capacidade de alteração e exclusão de tarefas, clientes possuindo somente capacidade de leitura.

### Decisões
- Melhorias de interface entram na Sprint 2.
- Sistema de Login e cadastro funcional para (v1.1), prioridade Alta.
- Ficam para versão futura: responsável pela tarefa, painel de desempenho, sistema de definir prioridades de tarefas, prazo de tarefa.
